# 2026-11-15 工作日志

## AI 聊天助手（ai-talk）六步开发交付

按 PRD.md / TECH_DESIGN.md / AGENTS.md 完成 React + TypeScript + Vite 单页应用，走 software-company 团队快速模式（主理人 → 工程师 → QA）。

### 技术决策
- Tailwind CSS 采用 v3.4 传统配置（postcss + tailwind.config.js），避免 v4 配置差异。
- 浏览器直连智谱会被 CORS 拦截，用 `vite.config.ts` 的 `server.proxy` 把 `/zhipu` 转发到 `https://open.bigmodel.cn`（changeOrigin + rewrite 去前缀）；前端请求同源相对路径。
- SSE 用 `fetch` + `response.body.getReader()` + `TextDecoder` 手写解析（EventSource 不支持 POST），处理跨 chunk 半行、`\r\n`、非 data 行、非法 JSON、`[DONE]`、末尾残留、AbortController 取消。
- Markdown 用 react-markdown v9（该版本 `code` 组件**不提供 `inline` prop**，靠 `language-` className + 换行判断 inline/block）；语法高亮用 `PrismLight` 按需注册 25 语言 + oneDark，把 JS 产物从 919 kB 降到约 399 kB。
- LocalStorage 键 `ai-talk:messages:v1`；400ms 防抖写入 + beforeunload flush + 流结束 finally 同步写入。
- 微信风：`#EDEDED` 背景、用户气泡 `#95EC69` 右对齐、AI 白色气泡左对齐。

### 智谱 API 关键事实（核对 docs.bigmodel.cn，2026-11-15）
- 端点 `POST https://open.bigmodel.cn/api/paas/v4/chat/completions`，`Authorization: Bearer <API Key>`，body `{model, messages, stream}`；SSE 以 `data: [DONE]` 结束，正式回答在 `choices[0].delta.content`。
- **`glm-4-flash` 已从官方可用模型列表移除**；免费 GLM-4 级文本模型为 `glm-4-flash-250414`、`glm-4.5-flash`、`glm-4.7-flash`。本项目默认 `glm-4.5-flash`（实测可用）。
- `glm-4.5-flash` 会先返回 `reasoning_content`（思考过程），正式回答仍在 `content`；当前实现忽略 reasoning_content 属设计取舍，界面不会空白。
- **API Key 必须是完整的 `id.secret` 两段式**；只有 32 位 ID 会在鉴权阶段返回 HTTP 401「令牌已过期或验证不正确」（与模型名、代理、CORS 无关）。密钥获取页：`https://bigmodel.cn/usercenter/proj-mgmt/apikeys`。

### 安全约定
